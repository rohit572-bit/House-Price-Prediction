# House-Price-Prediction
This project focuses on predicting house prices using advanced machine learning techniques based on various property features such as location, size, number of rooms, and overall quality. The dataset contains 79 explanatory variables describing different aspects of residential homes, making it a comprehensive regression problem.
The goal is to build a predictive model that accurately estimates property values and provides insights into the most influential factors affecting house prices. The project applies data cleaning, exploratory data analysis (EDA), feature engineering, and model optimization techniques to enhance prediction performance.

Key steps:

Data preprocessing and handling missing values

Exploratory data analysis to uncover patterns and correlations

Feature selection and transformation

Model development using Linear Regression, Decision Tree, Random Forest, and XGBoost

Model evaluation using RMSE, MAE, and R² metrics

Objective:
To develop a robust and interpretable model capable of predicting house prices with high accuracy — enabling data-driven decision-making for real estate valuation and investment analysis.
